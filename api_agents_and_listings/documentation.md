# Domain API Group 1: Agents & Listings

Group 1, Agents & Listings, is the part of the Domain API that connects researchers to the active property market as it appears on Domain. It is primarily about listings: the residential properties advertised for sale, rent or sold; the commercial properties and businesses being marketed; and the agencies, agents and development projects associated with those listings. For someone new to Domain data, this group is best understood as a live view of advertised market activity rather than a complete administrative record of every property transaction in Australia. The listing search endpoints let users find records by suburb and postcode or by drawing a GeoJSON polygon using the geoWindow parameter. This makes the group useful for place-based research questions, such as examining what kinds of dwellings are being advertised in a suburb, how asking prices or rents vary across an area, or how listing activity differs between neighbourhoods. Residential listing history extends back to around 2000, although records are sparse before 2018, while commercial, business and project listings mainly represent current and recent activity. The data is refreshed daily, so queries return a current API response rather than a static downloadable dataset. Beyond the listing itself, this API group also exposes the market actors behind the advertisement. Researchers can search for agencies, look up agency profiles and active listings, search for agents by name, retrieve agent profiles and associated listings, and inspect new-development projects. Project records describe the development as a whole, while the individual child listings for units or lots must be retrieved separately. These relationships allow users to move from a property advertisement to the agency, agent or project context that produced it. There are important limits to plan for when using this group. Each API call costs one credit, and listing search results are capped at 1,000 records per query, so broad searches may need to be refined by geography, listing type or other filters, or paged through using a cursor sweep. Sold listings should also be interpreted carefully: they only include properties that were advertised on Domain and therefore should not be treated as a complete record of all market transactions. The Group 1 endpoint reference in metadata/metadata.md documents the available parameters, response fields and limits, and the notebook-1-listings-search training material demonstrates how to search listings and page beyond the 1,000-record cap.
